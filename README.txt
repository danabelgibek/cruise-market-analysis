# Cruise Market Analysis — Visualizations

These four PNG files were exported from the outputs already saved in the provided Jupyter notebook.

- `correlation_heatmap.png` — Spearman correlation matrix of selected numerical features.
- `price_per_night_by_season.png` — distribution of price per night by season.
- `monthly_price_cycle.png` — monthly average and median price per night.
- `average_price_per_night_by_company.png` — mean and median price per night by cruise company.

Copy this `images` folder into the root of your GitHub repository.
